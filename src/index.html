Luku 1

Miten tämä toimii?

Sivunkääntö sidotaan suoraan vierityksen etenemiseen.

Tämä kirja on toteutettu pelkällä HTML + CSS + JavaScript -yhdistelmällä. Kirja pysyy paikoillaan keskellä näkymää, ja ainoa asia johon käyttäjä vaikuttaa, on vierityksen määrä.

Vierityksen suhteellinen eteneminen muunnetaan jokaiselle sivulle omaksi 0-180° käännökseksi. Sivuilla on myös varjostus, joka voimistuu käännön edetessä, jolloin efekti näyttää fyysisemmältä.

Luku 2

Rakenne sivujen takana

Jokainen elementti on "lehti", joka kääntyy muiden päällä.

Jokainen .page-elementti on oikean puolen sivu, jonka transform-origin on vasemmassa reunassa. Kun se käännetään rotateY-muunnoksella negatiiviseen kulmaan, se ikään kuin kääntyy oikealta vasemmalle, kuten oikeanpuoleinen sivu aidossa kirjassa.

Lisäksi sivulle annetaan pieni translateZ-syvyys sekä dynaaminen box-shadow, jotta sivut eivät mene täysin "tasaisesti" päällekkäin.

Luku 3

Miten otan tämän käyttöön?

Kopioi, muokkaa tekstit, lisää sivuja.

Käytännössä riittää, että kopioit tämän tiedoston omalle palvelimellesi ja muokkaat sivujen sisältöä. Voit lisätä uusia sivuja kopioimalla <article class="page">...</article> -blokkeja.

Muista myös säätää body { min-height: ... }-arvoa, jotta vieritystä riittää jokaiselle sivulle. Esimerkissä on neljä "lehteä": etukansi, kolme sisäsivua ja takakansi.

Kiitos vierailusta

Tästä layoutista on helppo tehdä esimerkiksi tarinallinen esittely, portfolio, tuotteen "story book" tai interaktiivinen dokumentaatio.

Halutessasi voit yhdistää tämän React-, Vue- tai muuhun frontend-frameworkiin ja hakea sivujen sisällöt esimerkiksi CMS-järjestelmästä.
